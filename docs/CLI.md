# Marmara PDF command line

Reference for `marmara` 0.1.0. Generated by `marmara docs` — do not edit by hand.

## Conventions

* Results are JSON on stdout. On failure: {"ok": false, "error": …} and a non-zero exit code.
* The input file is never changed unless --overwrite is given without --output. Results go to --output, or next to the input as <name>.<command>.pdf (a free name is chosen).
* Pages are 1-based: "3", "1-4,7", "5-", "all".
* Tool-calling LLMs can pass JSON instead of flags: marmara call <command> '{"input": "C:/docs/a.pdf", …}' (parameter names as in marmara commands).
* Coordinates are points (1/72 inch) measured from the top-left corner of the page as displayed (rotation applied), y grows downwards — the same frame as an image from to-images (pixel = point × dpi / 72). Rectangles are x0,y0,x1,y1.
* Encrypted PDFs: pass --password; results keep the same password.
* Digitally signed PDFs: comments and form values are added as incremental updates (signatures stay valid); changes that rewrite the file require --break-signatures.

## Inspect

### `compare`

Compare two versions word by word. Optionally write a marked-up copy of the new version (added text green, removed text as red notes).

```
marmara compare <old> <new> [options]
```

| Argument / option | Type | Description |
|---|---|---|
| `<old>` | file | Earlier version. (**required**) |
| `<new>` | file | Later version. (**required**) |
| `--output` / `-o` | file | Write a marked-up copy of the new version here. |
| `--overwrite` | flag | Allow replacing an existing output file. Without an output path, the input file itself is replaced. |
| `--max-changes` | int | Maximum changes listed (default 300). (default `300`) |
| `--password` | text | Password of an encrypted input PDF. The result keeps the same password. |

Examples:

```
marmara compare v1.pdf v2.pdf
marmara compare v1.pdf v2.pdf -o changes.pdf
```


### `edit-text`

Edit existing text in the page content (not an overlay): replace a phrase everywhere, or rewrite/delete/restyle/move one block.

Find mode: --find/--replace changes every block containing the phrase (paragraphs re-flow to their width). Block mode: --page and --block (from text-blocks) with --text (empty text deletes the block). The original font is kept when it has every glyph; otherwise a built-in font with full Unicode/Turkish support is used and reported as substituted.

```
marmara edit-text <input> [options]
```

| Argument / option | Type | Description |
|---|---|---|
| `<input>` | file | PDF file to read. (**required**) |
| `--find` | text | Phrase to replace (find mode). |
| `--replace` | text | Replacement text (find mode). |
| `--match-case` | flag | Case-sensitive find (default true). |
| `--first-only` | flag | Only change the first occurrence. |
| `--pages` | text | Pages to work on, 1-based: "all", "3", "1-4,7", "5-" (default: all). |
| `--page` | int | Page of the block (block mode). |
| `--block` | text | Block id from text-blocks (block mode). |
| `--text` | text | New text of the block; empty deletes it (block mode). |
| `--size` | number | New font size in points. |
| `--color` | text | Colour as #rrggbb. |
| `--family` | sans\|serif\|mono | Re-typeset in a built-in family: sans, serif or mono. |
| `--move` | x,y | Move the block by "dx,dy" points (display coordinates, y down; block mode). |
| `--output` / `-o` | file | Where to write the result. Default: next to the input as <name>.<command>.pdf (never replaces an existing file unless overwrite is set). |
| `--overwrite` | flag | Allow replacing an existing output file. Without an output path, the input file itself is replaced. |
| `--password` | text | Password of an encrypted input PDF. The result keeps the same password. |
| `--break-signatures` | flag | The input is digitally signed and this change rewrites the file, invalidating the signatures. Set to proceed anyway. |

Examples:

```
marmara edit-text contract.pdf --find "2025" --replace "2026"
```

## Comments

### `annotate`

Add a comment or markup: highlight/underline/strikeout found text, sticky note, text box, rectangle, ellipse, line, arrow, freehand ink or image.

Highlight, underline and strikeout take --find (marks every match; Turkish-aware) or --page with --rect. Notes need --page --at --text; text boxes --page --rect --text; shapes --page --rect; lines/arrows --page --from --to; ink --page --points; images --page --rect --image. Annotations stay editable in Marmara PDF and other PDF readers. On signed files they are added as an incremental update, so signatures stay valid.

```
marmara annotate <input> [options]
```

| Argument / option | Type | Description |
|---|---|---|
| `<input>` | file | PDF file to read. (**required**) |
| `--type` | highlight\|underline\|strikeout\|note\|freetext\|rect\|ellipse\|line\|arrow\|ink\|image | Kind of annotation. (**required**) |
| `--find` | text | Text to mark (highlight/underline/strikeout). |
| `--pages` | text | Pages searched with --find (default all). |
| `--match-case` | flag | Case-sensitive --find. |
| `--whole-word` | flag | Whole-word --find. |
| `--max-matches` | int | Mark at most this many matches (default 500). (default `500`) |
| `--page` | int | Page number (1-based) for placed annotations. |
| `--rect` | x0,y0,x1,y1 | Rectangle "x0,y0,x1,y1" (points, top-left origin). |
| `--at` | x,y | Note position "x,y". |
| `--from` | x,y | Line/arrow start "x,y". |
| `--to` | x,y | Line/arrow end "x,y". |
| `--points` | text | Ink strokes: "x,y x,y x,y; x,y x,y" (strokes separated by ";"). |
| `--text` | text | Note / text-box text, or a comment attached to markup and shapes. |
| `--color` | text | Colour #rrggbb (defaults per type). |
| `--opacity` | number | 0–1 (default 1, highlights 0.45). |
| `--width` | number | Line width in points (shapes, lines, ink; default 2). |
| `--fill` | text | Fill colour for rect/ellipse. |
| `--font-size` | number | Text-box font size (default 12). |
| `--image` | file | PNG/JPEG for type image. |
| `--author` | text | Author shown in comment lists. |
| `--output` / `-o` | file | Where to write the result. Default: next to the input as <name>.<command>.pdf (never replaces an existing file unless overwrite is set). |
| `--overwrite` | flag | Allow replacing an existing output file. Without an output path, the input file itself is replaced. |
| `--password` | text | Password of an encrypted input PDF. The result keeps the same password. |

Examples:

