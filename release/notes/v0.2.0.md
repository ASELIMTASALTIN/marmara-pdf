## Marmara PDF 0.2.0

**New: Assistant** — a local AI side panel (Ctrl+J or the Assistant button). Ask in Turkish or English and it works on the open PDF: reads and summarises, highlights, comments, edits text, adds page numbers, headers and watermarks, rotates/moves/deletes pages, marks text for redaction, fills forms, adds bookmarks, runs OCR, compresses and exports to Word. Every change can be undone. It runs entirely on your computer (llama.cpp engine, GPU via Vulkan or CPU); the first time it offers to download its model (Gemma 4 E2B heretic-ara, 3.1 GB).

**New: command line and MCP server** — `marmara <command>` exposes every feature for scripts; `marmara mcp` lets local LLM apps use Marmara PDF as tools.

**New: dark mode** — light, dark or same as Windows (sun/moon button and Settings menu).

**New: automatic updates** — Settings ▸ Check for updates downloads, verifies and installs new versions from GitHub.

Also: redaction, compression, PDF/A, printing, form creation, object editing, document comparison, headers/footers/Bates/watermarks, bookmarks, batch processing, tabs and XFDF comment exchange.
